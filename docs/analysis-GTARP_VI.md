## Как он пишет (что нравится)

- **Одна мысль на пост.** Заголовок-факт, иногда 1–2 строки пояснения. Без «по данным источников»,
  без вступлений. Пример: «К аллигаторам не подходим — они слишком злые и большие».
- **Голос человека, не редакции.** «Записали как это выглядит», «Кратенько пробежался, чтобы
  показать вам», «Мы дожили. Я не верю.», «Узнаем правда или нет, когда затестим сами 🤔».
- **Сленг и шутки:** «имба», «стрипуха», «пивсик», «обсёр», «бицуха», «рескин GTA 4 😎».
- **КАПС на главном слове:** «ЧИТ-КОДЫ», «ПОЛМИЛЛИОНА», «БОЛЕЕ 200 ЧАСОВ».
- **Метки в начале:** «СПОЙЛЕР.», «🔞», «❗️», «⚡», «🔔» — сразу понятно, что внутри.
- **Реакция как голосование:** «❤️ — да тут база / 👎 — кому нравится этот гундеж». Даёт в 3–5 раз
  больше реакций, чем обычный пост.
- **Видео = главный контент.** Короткие клипы 5–30 с со стримов (Бустер, Мэддисон и др.),
  иногда 1–5 мин («погоня на 3 звёздах», «радиостанции»). Подпись описывает, что на видео.
- **Подвал одинаковый:** «6️⃣ Подписаться · 💬 Наш форум» — ссылки-приглашения.
- **Без ссылки на источник** почти везде.

## Что НЕ стоит копировать

- **Неточности и вброс.** «Список чит-кодов» и часть «фактов» ничем не подтверждены; «Возможно
  спойлер: у Лусии есть ребёнок» — догадка по скрину. Для нас правило остаётся: слух помечаем.
- **Чужие видео без указания автора.** Клипы со стримов — чужой контент. Минимум — подпись
  «🎥 клип: стрим Бустера», и не брать то, что автор просил не перезаливать.
- **Реклама, замаскированная под пост** (пост про Arizona Online собрал 20 🤡).
- Ошибки в тексте («больле», «столкнвоений», «предаказ») — у нас текст проверяет нейросеть.

Технически возможно бесплатно:
- **Где брать видео:** Twitch Clips API (бесплатно, клипы по игре GTA VI, сортировка по просмотрам),
  YouTube Data API (бесплатно 10 000 единиц/сутки — Shorts и ролики по запросу), Reddit
  (r/GTA6, r/GTA — видео, но из GitHub Actions Reddit часто отвечает 403/404).
  X/Twitter API — платный, не подходит. Другие Telegram-каналы читать может только «пользователь»
  (Telethon), а не бот — нужен отдельный аккаунт Telegram.
- **Скачать клип:** `yt-dlp` (бесплатно). Бот может отправить видео до 50 МБ (`sendVideo`).
- **Нейросеть «отбирает»:** по названию клипа, числу просмотров и описанию решает — интересно
  или нет, и пишет подпись в стиле канала (1–2 строки, шутка, метка СПОЙЛЕР/🔞).
  Смотреть само видео бесплатная Gemini умеет (до ~20 запросов в сутки) — можно для лучших клипов.
