## Журнал
### 2026-11-16
- Создан проект `gta6-news-bot`, добавлены CLAUDE.md (правила для Claude) и PROGRESS.md (этот журнал).
- Проверены источники, рабочие внесены в config.yaml.
- Написаны модули бота. Решения:
  - Смысловой дедуп в два слоя: дешёвая схожесть заголовков (слова + посимвольно) и поле
    `duplicate` от Gemini (ловит дубли между русскими и английскими заголовками).
  - «Второе подтверждение» для источников уровня rumor: текстовая схожесть с недавними новостями
    от official/high/medium ИЛИ поле `corroborated` от Gemini.
  - DRY_RUN не сохраняет state.json и пишет `out/preview.html` (посты как в Telegram) и `out/report.md`.
  - В Actions расписание работает только при переменной `PUBLISH=true`.
- Прогон без Gemini: 814 записей → 434 про GTA 6 → 232 свежих, дубли между сайтами отсеиваются.
  Прогон с подставным ответом Gemini: карточки, подписи, preview собираются; HTML экранируется.

### 2026-11-17
- Первый настоящий dry-run завис: `gemini-flash-latest` «думал» ~80 с на статью при таймауте 90 с,
  а в неделю релиза ещё и отвечал 503 (high demand). Исправлено:
  - основная модель `gemini-3.5-flash` + `thinking_level: low` (~15 с на статью), запасные — flash-latest и flash-lite;
  - таймаут Gemini вынесен в config; при таймауте/503 бот сразу переходит к запасной модели;
  - если модель не принимает `thinking_level`, бот повторяет запрос без него.
- Flash-Lite заявил `corroborated: true` при пустом списке недавних новостей → в main.py
  поля `corroborated`/`duplicate` засчитываются, только если в показанном списке были подходящие записи.
- Google News отдал корейскую страницу Newswire («뉴스와이어») → запрос сужен до
  `site:rockstargames.com/newswire/article`, заголовки с иероглифами/хангылем отбрасываются.
- Прогон на 12 статьях: 2 в очередь, 5 skip (не про GTA 6), 2 дубля пойманы Gemini, 3 ниже порога.
- Выяснилось: бесплатный Gemini Flash — 20 запросов/сутки на модель (`GenerateRequestsPerDayPerProjectPerModel-FreeTier`).

### 2026-11-18 — переход на бесплатную связку Groq + Gemini
- Пользователь не хочет платить за токены → искали лучший бесплатный вариант:
  - GitHub Models — закрыт с 30.07.2026; OpenRouter без оплаты — 50 запросов/сутки (мало);
  - **Groq** (бесплатно, без карты): gpt-oss-120b, qwen3.8-27b, gpt-oss-20b — ~1000 запросов и 200 тыс.
    токенов в сутки, 8 тыс. токенов в минуту на модель, строгий JSON. Ответ ~1 с.
- `bot/llm.py` переписан: цепочки моделей разных провайдеров (`triage_chain`, `writer_chain` в config),
  провайдер без ключа пропускается, суточный лимит/зависание → модель выбывает до следующего запуска.
- Тест авторов: Qwen пишет живее, но выдумывает («игра вышла вчера» до релиза) → автор — Gemini Flash
  (таймаут 40 с, 1 повтор), запасной — gpt-oss-120b. Разбор статей — gpt-oss-120b.
- Дубли: модель в большом промпте пропускала повторы (Люсия ×3, номинации TGA ×3) → добавлена отдельная
  узкая проверка `same_event` перед написанием текста. Повторы отсекаются.
- `keywords_title_only: true` — GTA 6 должна быть в заголовке: меньше мусора, меньше запросов.
- Известное: r/GTA6 отдаёт 404 (Reddit режет ботов); Google News может пометить свежей датой
  старую статью Rockstar Newswire.

### 2026-11-18 (вечер) — модерация через бота
- Реальная ошибка с каналом: публичного канала `@gta6hot_news` НЕ существует (t.me/gta6hot_news — заглушка
  для несуществующего адреса). Поэтому «chat not found». Плюс бот подписывался только на сообщения/кнопки
  и не видел событие «меня добавили в канал».
- Теперь бот сам находит канал по событию `my_chat_member` (добавили админом с правом публикации) и пишет
  об этом в личку. `TELEGRAM_CHANNEL_ID` стал необязательным. Команда `/channel` — какой канал подключён.
- Модерация: черновики в личку с кнопками ✅ / ❌. Только свежие (≤6 ч) и важные (≥8/10), не больше 3 в сутки,
  ночью (01–07 по Киеву) не шлём. ✅ → публикация сразу (пауза 40 мин между постами сохраняется).
- Каждый запуск после сбора новостей 11 минут «слушает» Telegram (long polling) — пост выходит почти сразу
  после нажатия. Cron — каждые 15 минут. Запуск в Actions работает без флага PUBLISH (всё равно ничего не
  уходит в канал без ✅); выключатель — переменная `BOT_OFF=true`.
- Если канал недоступен, одобренный пост не выкидывается, а ждёт подключения канала.

### 2026-11-18 (утро) — бот в GitHub Actions, кнопки быстрее
- Первый облачный запуск и 6 запусков по расписанию — все зелёные, `state.json` коммитится сам.
- Оказалось: cron `*/15` GitHub выполняет примерно раз в час. При прослушивании 11 мин кнопка ✅
  могла ждать до часа. Теперь каждый запуск слушает Telegram 50 мин (`moderation.listen_minutes`),
  тайм-аут задачи 70 мин — кнопки срабатывают за секунды почти круглосуточно. Actions для публичного
  репозитория бесплатны, так что это ничего не стоит.
