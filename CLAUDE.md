# CLAUDE.md — GTA 6 News Bot

Инструкции для Claude Code при работе с этим проектом.

## Что это
Бот, который полностью автоматически ведёт Telegram-канал «GTA 6 | Горячие новости»
(@gta6_hotnews — адрес канала; бот: @gta6hot_news_bot). Запускается в GitHub Actions по cron (на деле ~раз в час, каждый запуск слушает кнопки 50 мин), сервер не нужен.
Цепочка: RSS → фильтр «про GTA 6» → дедупликация → текст статьи → LLM (Groq/Gemini, JSON) →
очередь → черновик админу в личку раз в час (+ срочное сразу) → кнопка ✅ →
карточка по шаблону из Figma → sendPhoto в канал. Без ✅ в канал ничего не уходит.
Видео: клипы Twitch (игра GTA VI) + шортсы YouTube → самые «залетающие» → yt-dlp скачивает →
Gemini смотрит видео и пишет короткую подпись (или отсеивает) → черновик-видео в личку → ✅ → sendVideo по file_id.
Рубрики: 🗺 гайды (поле `guide` от LLM, шаблон guide.png), 🌙 итоги дня, 📊 опрос недели (`config.yaml → extras`).
Стиль постов — как у @GTARP_VI: коротко, от лица живого фаната (разбор: docs/analysis-GTARP_VI.md).

## Пользователь
- Учится программировать. После каждого шага коротко объяснять, что сделано и зачем.
- Общение и все тексты для людей (README, логи, посты) — на русском.

## Стек
- Python 3.12 в Actions (локально у пользователя 3.10 — код должен работать на обоих:
  без `type X = ...`, без новых фич 3.11+ вроде `tomllib`-зависимой логики и т.п.).
- Зависимости: feedparser, httpx, google-genai, Pillow, PyYAML. Без тяжёлых фреймворков.

## Структура
- `bot/fetch.py` — загрузка RSS/страниц, фильтр по ключевым словам, текст статьи.
- `bot/dedupe.py` — state.json, дедуп по URL/хэшу заголовка, смысловая похожесть за 48 ч.
- `bot/llm.py` — Gemini, системный промпт из config.yaml, JSON-схема, валидация.
- `bot/card.py` — карточка 1280x720: фон-шаблон (`assets/templates/`) + заголовок Unbounded; запасной вариант — отрисовка кодом.
- `tools/make_templates.py` — собирает шаблоны: фото Майами (`assets/bg/`, Unsplash) + цветокоррекция + 3D-монета/плашка/сетка.
- `bot/clips.py` — видео: Twitch/YouTube API, yt-dlp, подпись Gemini по самому видео, черновики и публикация.
- `bot/extras.py` — «Итоги дня» (22:00) и опрос недели: черновик с ✅ → sendMessage / sendPoll в канал.
- `bot/moderation.py` — черновики в личку, кнопки, расписание, автоопределение канала (my_chat_member).
- `bot/publish.py` — Telegram sendPhoto, HTML-подпись, правила публикации и лимиты.
- `bot/main.py` — оркестрация одного запуска.
- `bot/check_feeds.py` — проверка источников и отчёт (`python -m bot.check_feeds --all`).
- `bot/util.py` — конфиг, .env, логи без секретов, HTTP с повторами.
- `config.yaml` — ВСЕ настройки (источники, пороги, лимиты, промпт). Не хардкодить их в коде.
- `state.json` — состояние, коммитится обратно в репо из Actions.

## Правила
- Секреты только из env: TELEGRAM_BOT_TOKEN, TELEGRAM_ADMIN_ID, TELEGRAM_CHANNEL_ID, GEMINI_API_KEY, GROQ_API_KEY,
  TWITCH_CLIENT_ID, TWITCH_CLIENT_SECRET, YOUTUBE_API_KEY.
  Никогда не писать их в код, логи, коммиты. `.env` в .gitignore.
- `type = leak` — никогда не публиковать. Остальные пороги — в config.yaml.
- Пользователь не хочет платить за токены — только бесплатные тарифы (Groq + Gemini). Figma AI-генерацию не использовать (платные кредиты).
- Не запускать бота локально, когда он работает в GitHub Actions: два getUpdates с одним токеном воруют нажатия.
- Нейросеть училась до релиза GTA 6 — в промптах прямо сказано, что игра вышла 18.11.2026 (иначе она зовёт настоящие клипы «фейком»).
- Пауза ≥ 15 мин между постами, не больше 30 в сутки; черновики ночью (00–07 Europe/Kyiv) не шлём.
- Новости: сбор каждые 15 мин внутри запуска (`moderation.refresh_minutes`), черновик раз в час (`moderation.schedule`) + срочные.
- Видео: защита от повторов (`state.clip_history`, 3 суток): тот же момент стрима (vod_id ± 3 мин), один стример раз в 12 ч,
  отпечатки кадров (dHash кадра в секунду, `clips.fingerprints/same_footage`) — ловит перезаливы и другие нарезки,
  и Gemini видит описания показанного и ставит `repeat`.
- Figma Starter: лимит вызовов MCP в день — экспорт шаблонов может упереться; тогда Export PNG вручную из слоя `art`.
- Ошибки сети/API не должны валить весь запуск: ретраи с экспоненциальной паузой, лог, продолжить.
- Проверка изменений: `DRY_RUN=1 python -m bot.main` — пишет карточки и тексты в `out/`.
- После заметного шага обновлять PROGRESS.md.
