# 🎮 GTA 6 | Горячие новости — бот для Telegram-канала

Бот ведёт канал [@gta6_hotnews](https://t.me/gta6_hotnews). Каждые 15 минут собирает новости про
GTA 6 из ~20 источников, отбрасывает дубли и мусор, бесплатная нейросеть (Groq + Gemini) пишет пост
на русском, бот рисует карточку по шаблону из Figma и **присылает тебе в личку на одобрение**.
Нажал ✅ — пост в канале. Сервер не нужен, всё крутится в GitHub Actions, управление — с телефона.

```
RSS (20 сайтов) → «про GTA 6» → дубли → нейросеть (тип, важность, текст) → очередь
   → по расписанию лучшая новость тебе в личку [✅ / ❌] → ✅ → карточка + пост в канал
```

## Как это выглядит для тебя

Бот **@gta6hot_news_bot** сам пишет тебе в Telegram:

| Когда | Что приходит |
|---|---|
| 🌅 **Утро** 9:00–12:00 | одна лучшая свежая новость |
| 🍔 **Обед** 13:00–16:00 | одна лучшая свежая новость |
| 🌙 **Вечер** 18:00–22:00 | одна лучшая свежая новость |
| 🚨 **Срочно** — в любое время | важность 9–10/10 или официальное от Rockstar/Take-Two, не больше 2 в сутки |
| 🎥 **Видео** 10:00–23:00 | до 5 клипов в день: самые залетающие моменты с Twitch и YouTube, подпись пишет Gemini, посмотрев видео |
| 😴 Ночь 01:00–07:00 | ничего |

Время — киевское. В каждом сообщении: карточка, готовый текст поста и две кнопки:

- **✅ Опубликовать** — пост уходит в канал за секунды (каждый запуск «слушает» кнопки ~50 минут, а GitHub запускает бота примерно раз в час);
- **❌ Пропустить** — выкинуть.

Если два поста одобрены подряд, второй выйдет через 30 минут после первого (чтобы не было «залпа»).

Команды боту в личке: `/start` — твой chat id, `/channel` — какой канал подключён.

**Канал бот находит сам**: добавь его в канал администратором с правом «Публикация сообщений» —
он напишет «📡 Подключил канал …».

Все числа (слоты, важность, срочность, лимиты) — в `config.yaml` → `moderation`.

## Видео

Бот каждый час смотрит свежие (за сутки) клипы Twitch по игре **Grand Theft Auto VI** и короткие ролики
YouTube по запросам из `config.yaml` → `clips.youtube.queries`. Берёт самые «залетающие» (просмотры в час),
скачивает (`yt-dlp`), отдаёт **Gemini посмотреть видео** — он отсеивает фейки, моды GTA 5 и скучное,
ставит метки СПОЙЛЕР / 🔞 (в Telegram такое видео будет размыто до нажатия) и пишет подпись в стиле
@GTARP_VI. В подписи всегда автор клипа со ссылкой.

Ключи бесплатные: `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` (dev.twitch.tv/console/apps),
`YOUTUBE_API_KEY` (Google Cloud → YouTube Data API v3). Без ключа источник просто пропускается.
Reddit без ключа отвечает 403 — не используется.

## Карточки (Figma)

Дизайн карточек живёт в Figma: файл **«GTA 6 Hot News — Card Templates»** (в твоих черновиках Figma).
Там три шаблона 1280×720: **ПОДТВЕРЖДЕНО**, **СЛУХ**, **ОФИЦИАЛЬНО** (для новостей Rockstar/Take-Two).
Бот берёт фон-шаблон и сам пишет заголовок шрифтом Unbounded в зону, где в макете стоит слой
`title (sample)`.

**Как поменять дизайн:** правишь шаблон в Figma → выделяешь слой `art` нужного шаблона →
Export PNG 1x → кладёшь в `assets/templates/` как `confirmed.png`, `rumor.png` или `official.png`
(с телефона — через сайт GitHub: Add file → Upload files). Если зону заголовка двигал — поправь
`config.yaml` → `card` → `template` (`title_x`, `title_bottom`, `title_width`).

## Запуск в GitHub (один раз, потом всё само)

1. **Репозиторий.** github.com → **New repository** → имя, например `gta6-news-bot` → **Public** →
   Create. Публичный — потому что для публичных репозиториев Actions бесплатны без ограничений
   (бот работает ~16 часов в сутки — в бесплатные 2000 мин/мес приватного не влезет).
   Ключи в публичном репозитории никто не видит: они в секретах. `.env` в репозиторий не попадает.
2. **Залить код** (это делает Claude с компьютера: `git push`).
3. **Секреты** — Settings → Secrets and variables → **Actions** → New repository secret (можно с телефона
   через браузер, в «полной версии» сайта):
   - `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
   - `TELEGRAM_ADMIN_ID` — твой chat id (бот пришлёт на `/start`)
   - `TELEGRAM_CHANNEL_ID` — `@gta6_hotnews` (запасной вариант; бот и так знает канал)
   - `GROQ_API_KEY` — [console.groq.com/keys](https://console.groq.com/keys), бесплатно
   - `GEMINI_API_KEY` — [aistudio.google.com/apikey](https://aistudio.google.com/apikey), бесплатно
   - `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` — [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps), бесплатно
   - `YOUTUBE_API_KEY` — [Google Cloud](https://console.cloud.google.com/apis/credentials), YouTube Data API v3, бесплатно
4. **Включить Actions**: вкладка **Actions** → «I understand my workflows, go ahead and enable them».
   Дальше бот работает сам каждые 15 минут.

**Важно:** когда бот заработал в GitHub, не запускай его одновременно на компьютере — два бота с одним
токеном будут «перехватывать» нажатия кнопок друг у друга.

### С телефона (приложение GitHub)
- Запустить прямо сейчас: Actions → **GTA6 News Bot** → **Run workflow**.
- Посмотреть, что бот делал: Actions → последний запуск → **bot** → **Запуск бота** (что нашёл,
  что пропустил и почему).
- Выключить бота: Settings → Secrets and variables → Actions → **Variables** → `BOT_OFF` = `true`.

## Нейросети (всё бесплатно)

- **Groq** — разбирает каждую статью (тип, важность, дубль): ~1000 запросов в сутки на модель, ответ ~1 с.
- **Gemini Flash** — пишет финальный текст (точнее всех по фактам), 20 запросов в сутки на модель.
- Кончился лимит или модель «перегружена» — бот берёт следующую из цепочки (`config.yaml` → `llm`).

## Правила (из `config.yaml`)

- `confirmed` → в очередь при важности ≥ 6, `rumor` → ≥ 8, `leak` → **никогда**.
- Источники уровня `rumor` (Google News, Reddit) — только если ту же новость дал надёжный источник.
- Дубли: по ссылке, по заголовку и отдельной проверкой нейросетью «это то же событие?» за 48 часов.
- Не больше 12 постов в канал в сутки, пауза между постами ≥ 40 минут.

## На компьютере (для отладки)

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```

В `.env` впиши ключи. Запуск: `.venv\Scripts\python -m bot.main`.
`DRY_RUN=1` — ничего не шлёт в Telegram, карточки и тексты кладёт в `out/` (открой `out/preview.html`).
Проверить источники: `.venv\Scripts\python -m bot.check_feeds --all`.
