# Фото для заставок

Все фото — с Unsplash, [лицензия Unsplash](https://unsplash.com/license): бесплатно, в том числе для
коммерческого использования, указывать автора не обязательно (но приятно).

| Файл | Где используется | Источник |
|---|---|---|
| `miami_teal.jpg` | ПОДТВЕРЖДЕНО | https://unsplash.com/photos/P4tbpnpz61Y |
| `miami_sunset.jpg` | СЛУХ | https://unsplash.com/photos/dS2L5bKTSaM |
| `miami_brickell.jpg` | ОФИЦИАЛЬНО | https://unsplash.com/photos/QtTHy9MUVoQ |
| `miami_palms.jpg` | ГАЙД | https://unsplash.com/photos/-8X6B5j8mU0 |

Заставки собирает `tools/make_templates.py` (фото + цветокоррекция + 3D-монета, плашка, сетка).
Поменять фото: положи новое сюда, укажи его в `THEMES` в скрипте и запусти
`python tools/make_templates.py --preview` (превью — `out/templates_preview.png`).
